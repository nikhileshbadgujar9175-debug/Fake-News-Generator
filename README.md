# Fake News Generator

A Python-based Fake News Generator project that generates fictional news content for educational and demonstration purposes.

## Features

- Generates fictional news articles
- Simple Python-based project
- Easy to run and understand
- Useful for learning Python programming

## Technologies Used

- Python
- Python libraries used in this project

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the Python file:

```bash
python Fake_News_Generator.py
```

## Example

The program generates fictional news content based on the user's input.

## Disclaimer

This project generates **fictional/synthetic news content** for educational purposes. The generated content should not be presented or treated as real news.
